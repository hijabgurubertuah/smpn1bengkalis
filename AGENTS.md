# Persistent Project Rules & Instructions

## CRITICAL UI DESIGN MANDATES

1. **STRICTLY NO HELPER TEXT / NO PETUNJUK TEKS / NO INSTRUCTION SUBTITLES:**
   - JANGAN PERNAH menambahkan teks petunjuk, helper text, subtitle bertele-tele, deskripsi panjang di bawah label input, atau teks panduan di UI.
   - User SANGAT TIDAK MENYUKAI teks petunjuk atau helper text pada tampilan UI.
   - Hapus semua helperText, teks catatan kecil, kalimat panduan, dan subtitle penjelas yang bertele-tele pada form dan seluruh komponen UI.
   - Buat UI bersih, ringkas, minimalis, dan to-the-point hanya menampilkan Label dan Input.

2. **UI CLEANLINESS:**
   - Gunakan nama label yang singkat dan jelas (contoh: "Foto Formal" bukan "Foto Profil Guru / GTK (Unggah foto resmi dengan rasio 1:1)").
   - Tidak ada teks instruksi seperti "Lengkapi biodata resmi Anda di bawah ini...", "Tuliskan nama lengkap beserta seluruh gelar...", "Unggah foto resmi...".
